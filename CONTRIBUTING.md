# Contributing

Thank you for helping make Python learning clearer and more welcoming.

## Good contributions

- Correct a technical or grammatical issue.
- Add a small example that reinforces one learning objective.
- Improve an exercise without introducing third-party dependencies.
- Add accessibility descriptions or clearer instructions.
- Propose a beginner project with requirements, steps, checks, and stretch goals.

## Workflow

1. Fork the repository and create a focused branch.
2. Keep explanations concise and define new terms before using them.
3. Clear notebook execution outputs before committing.
4. Run `python tools/validate_notebooks.py`.
5. Run `python -m unittest discover -s tests -v`.
6. Open a pull request explaining the learner benefit.

Do not include credentials, private data, large datasets, or copied copyrighted course material.
